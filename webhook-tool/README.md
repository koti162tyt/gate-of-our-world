# Панель вебхуков Discord

Локальная панель для игры в войсе: пишешь в Discord от имени любого персонажа,
создаёшь и переименовываешь вебхуки. Без зависимостей, только стандартная
библиотека Python 3.9+.

## Запуск

```powershell
cd "E:\Врата в чужой мир\webhook-tool"
python server.py
```

Открой в браузере: **http://127.0.0.1:3210**

Если `python` не найден — двойной клик по `start.bat`, он попробует `py -3`,
потом `python`, потом путь к встроенному интерпретатору.

Порт можно поменять: `set PORT=4000 && python server.py` (PowerShell:
`$env:PORT=4000; python server.py`).

## Аватары

Discord принимает аватар только двумя способами: публичная ссылка `https://…` или
data-URI через токен бота. Ссылки с фотостоков (pngtree и подобные) часто отдают
**403** на прямой запрос — Discord получает пустоту и ставит заглушку.

В панели на вкладке **Персонажи**:

- кнопка **Проверить** рядом с полем ссылки — говорит, картинка ли по ссылке и не
  блокирует ли сайт прямые запросы;
- кнопка **Фото** — выбрать файл с диска. Картинка обрезается до квадрата 256×256
  и уходит в Discord напрямую, без внешнего хостинга.

Для загрузки файлом нужен **токен бота и ID канала**: под каждого персонажа
создаётся отдельный вебхук с его именем и аватаром. Без токена фото сохранится
локально (предпросмотр покажет), но в Discord не попадёт — там нужна ссылка.

## Как подключить канал

Два способа, оба в панели на вкладке **Вебхук**.

### 1. По ссылке (быстрее всего)

Discord → канал → **Настройки канала → Интеграции → Вебхуки → Новый вебхук** →
**Копировать URL вебхука** → вставить в поле «Ссылка вебхука» → «Добавить по ссылке».

Токен бота не нужен. Переименование тоже работает: PATCH доступен владельцу
вебхука, поэтому имя сохраняется локально, а в Discord меняется только при
наличии токена бота.

### 2. Через бота (создание и переименование из панели)

1. https://discord.com/developers/applications → **New Application** → **Bot** →
   **Reset Token** → скопировать.
2. **OAuth2 → URL Generator**: scopes `bot`, права `Manage Webhooks`
   (+ `View Channels`, `Send Messages`).
3. Пригласить бота на сервер по ссылке.
4. В Discord включить **Настройки → Дополнительно → Режим разработчика**,
   правый клик по каналу → **Копировать ID**.
5. Вставить токен и ID канала в панель → «Создать через бота».

После этого вебхук создаётся, переименовывается и удаляется прямо из панели.

## Как говорить за персонажа

1. Вкладка **Сообщение** → слева выбери персонажа (Эрик, Ночь, Эрнест…).
2. Напиши текст → **Enter**. Справа сразу видно, как сообщение придёт в канал:
   аватар, имя, метка APP, время, разметка.
3. Уходит сообщением вебхука с именем и аватаром этого персонажа
   (галочка «имя в сообщении» вверху).

Предпросмотр понимает разметку Discord: `**жирный**`, `*курсив*`, `__подчёркнутый__`,
`~~зачёркнутый~~`, `` `код` ``, ``` ```блок кода``` ```, `> цитата`, `||спойлер||`,
ссылки `[текст](url)` и голые `https://…`. HTML экранируется — теги не пройдут.

Если галочку «имя в сообщении» снять — предпросмотр покажет имя самого вебхука,
и сообщение уйдёт именно так.

Персонажи, их аватары и токен лежат в `config.json` рядом с `server.py`.
Токен хранится в открытом виде: не выкладывай папку в общий доступ.

## Ограничения Discord

- Текст сообщения — до 2000 символов (панель считает).
- Вебхук не может редактировать чужие сообщения, только свои.
- Лимит примерно 30 сообщений в минуту на вебхук; на 429 панель сама ждёт и
  повторяет попытку.
- Имя вебхука — до 80 символов.

## API (если нужен свой клиент)

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/state` | текущее состояние без токена |
| POST | `/api/settings` | токен, ID канала, активный вебхук |
| POST | `/api/webhook/create` | создать вебхук через бота |
| POST | `/api/webhook/add` | добавить по ссылке |
| POST | `/api/webhook/rename` | переименовать |
| POST | `/api/webhook/delete` | удалить |
| POST | `/api/send` | `{text, character, webhookId?}` |
| POST | `/api/message/edit` | `{messageId, text}` |
| POST | `/api/characters` | `add` / `update` / `delete` |
